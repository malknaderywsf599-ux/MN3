# FreeLLM Menu

قائمة تفاعلية بـ `sh` لتشغيل **Claude Code على موديلات مجانية** (Gemini / GLM / Qwen / Mistral / NVIDIA)،
مع تحويل تلقائي للموديل اللي بعده لما الـ limit يخلص + ملخص (handoff) للتكملة من نفس المكان.

## الملفات (لازم يكونوا في نفس المجلد)
- `menu.sh`  القائمة (عربي / English)
- `server.js`  البروكسي (Node 18+، بدون مكتبات)
- `providers.json`  ترتيب الموديلات والـ limits

## التشغيل
```
sh menu.sh
```
1. من القائمة: **6** تثبيت Node و Claude Code (يحتاج Termux أو لينكس؛ على ArabTerm جرّب `pkg`).
2. **3** ضيف مفتاح API مجاني واحد على الأقل (مثلًا Gemini من aistudio.google.com).
3. **1** شغّل البروكسي، ثم **4** شغّل Claude Code.
4. **5** تشوف الاستهلاك ومين الموديل الشغال.

المفاتيح بتتحفظ في `~/.freellm/keys.env` (صلاحية 600).
متغيرات: `UI=en` للإنجليزي، `PORT=8787`, `NO_COLOR=1`, `FREELLM_HOME=...`.

## ملاحظات
- الأداة اتجرّبت على موديلات وهمية؛ جرّبها بمفاتيحك الحقيقية.
- أسماء الموديلات والـ limits المجانية في `providers.json` بتتغير؛ راجعها من موقع كل مزوّد.
- الموديلات المجانية أضعف من Claude، خصوصًا في الـ tool calls.
