# WebLinux

Linux حقيقي جوه المتصفح (محاكي v86) بشكل شبه Termux.

الملفات (كلها في نفس الفولدر):
- index.html  الصفحة
- style.css   الشكل
- config.js   الروابط والإعدادات
- keys.js     شريط الأزرار
- main.js     تشغيل المحاكي

لو صورة Linux ماتحملتش: نزّلها وحطها في images/ وغيّر bzimage في config.js.
